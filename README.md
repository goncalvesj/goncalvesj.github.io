# goncalvesj.github.io

Tech blog built with [Astro](https://astro.build/) and hosted on GitHub Pages.

## Development

```sh
npm install
npm run dev
```

## Validation

```sh
npm run build
```

## Content

Blog posts live in `content/` as Markdown files with frontmatter for `date`, `title`, `slug`, `categories`, and `tags`.

## Deployment

The site is deployed to GitHub Pages through the workflow in `.github/workflows/deploy.yml`.
